# スマッシュブロ (SMASH BRO)

スマホのブラウザで遊べる、大乱闘スマッシュブラザーズ風の 2D 対戦格闘ゲームです。
**HTML5 + JavaScript のみ**（ビルド不要・外部ライブラリはオンライン対戦の PeerJS だけ）で動きます。

## 遊びかた

`index.html` をブラウザで開くだけです。

```bash
# ローカルで確認する場合（どれでも可）
npx http-server -p 8080 .
python3 -m http.server 8080
```

スマホで `http://<PCのIP>:8080` を開いてください。**横持ち推奨**（縦持ちにも対応）。

## モード

| モード | 内容 |
|---|---|
| ローカル対戦 | 同じ画面で 2 人対戦。画面を左右に分割し、各プレイヤーが自分側の操作エリアを使います |
| CPU対戦 | オフライン 1 人用。CPU の強さ 3 段階（簡単 / 普通 / 難しい）、CPU 人数 1〜3 体（1vs1 / 1vs2 / 1vs3） |
| オンライン対戦 | PeerJS (WebRTC) によるリアルタイム 1vs1。ルーム作成 / ルームID入力で参加 / ランダムマッチ |

## 操作（タッチ専用）

- **画面左側**：仮想ジョイスティック（移動・しゃがみ・すり抜け降り）
  - 触れた場所にスティックが出る「フローティング方式」
- **画面右側**：4 つのボタン
  - **攻撃** … 通常攻撃（連打で 3 段コンボ / 空中では空中攻撃 / 爆弾所持中は投擲）
  - **スマッシュ** … 押しっぱなしで溜め、離すと発動。スティックの向きで 横 / 上 / 下スマッシュ
  - **ジャンプ** … 空中でもう一度押すと 2 段ジャンプ。長押しで高く跳ぶ
  - **特殊** … キャラクター固有の必殺技

2 人対戦時は左右それぞれの端に 1 セットずつ操作系が配置されます。

## ゲームルール

- ダメージは **パーセント制**（0% スタート）。% が高いほど大きく吹き飛びます
- 画面外（ブラストゾーン）に吹き飛ぶと **SMASH!**（撃墜）で 1 ストック減少
- 初期ストックは 3（1 / 2 / 3 / 5 から選択可）
- アイテムがランダムで落下。触れるか攻撃を当てると取得できます

ノックバックは `((% × 0.1 + % × ダメージ × 0.005) × (200 /(重さ+100)) × 1.45 + 6) × 吹き飛ばし率 / 100 + 基礎値`
というスマブラ風の計算式で、キャラの **重さ** と **蓄積ダメージ** が効いてきます。

## キャラクター（6 体）

| キャラ | タイプ | 特殊技 |
|---|---|---|
| アキラ | バランス型 | エネルギー波（中距離の飛び道具） |
| ゴウ | パワー型 | 剛拳（近距離に超威力・スーパーアーマー付き） |
| レイ | スピード型 | 疾風ステップ（高速移動＋接触ダメージ） |
| ユキ | 遠距離型 | 氷の矢（直線の飛び道具・命中で減速） |
| シオン | テクニカル型 | 影分身（無敵で後方へワープし反撃機会を作る） |
| テツ | 重量級 | 鉄壁（一定時間スーパーアーマー） |

全キャラ共通で **通常攻撃（3 段） / 横スマッシュ / 上スマッシュ / 下スマッシュ / 空中攻撃 / 特殊技** を実装。

## ステージ（3 種）

- **草原** … 平坦な地面＋左右と中央の浮島。定番ステージ
- **遺跡** … 中央に高い足場。左右の床は攻撃で壊れ、一定時間後に復活
- **空中要塞** … 浮島が多く落ちやすい高難度ステージ（動く足場あり）

## アイテム（5 種）

- **回復** … ダメージ % が 25 回復
- **爆弾** … 持って攻撃ボタンで投擲、着弾で爆発
- **バット** … 一定時間 攻撃力アップ
- **バリア** … 一定時間 ダメージ無効
- **スピードアップ** … 一定時間 移動速度アップ

## オンライン対戦のしくみ

- **PeerJS (WebRTC DataChannel)** を利用し、サーバー不要の P2P 通信
- **ホスト権威型**：ホストが物理演算を実行し、20Hz で状態を送信。ゲストは入力を 60Hz で送信
- ゲスト側はローカル予測＋補間（受信した座標へなめらかに寄せる）で体感遅延を軽減
- 切断時は自動でメニューへ戻ります

## ファイル構成

```
index.html          画面・UI のマークアップ
css/style.css       メニュー / HUD のスタイル
js/util.js          数学ユーティリティ・定数・効果音（WebAudio 合成）
js/characters.js    6 キャラのステータスと技データ
js/stages.js        3 ステージの地形データ
js/items.js         5 種のアイテム定義
js/input.js         タッチ操作・仮想パッドの描画とレイアウト
js/engine.js        物理 / 判定 / ノックバック / アイテム / 撃墜処理
js/ai.js            CPU の思考ルーチン（3 段階）
js/render.js        アニメ調 2D 描画（ベクター・ドット絵不使用）
js/net.js           オンライン対戦（PeerJS）
js/ui.js            メニュー・キャラ選択・結果画面
js/main.js          ゲームループ
```

## 描画方針

ドット絵は一切使わず、Canvas 2D のベクター描画のみで
「少し厚塗りのアニメ調（スマブラX 風）」を表現しています。

- キャラはボーン（関節角度）から毎フレーム組み立て、カプセル＋グラデーションで描画
- はっきりした輪郭線 + ハイライト + 影で立体感を出す
- 攻撃・ヒットエフェクトは斬撃カーブ・リング・パーティクルの合成
- グラデーションはキャッシュして再利用し、スマホでも 60fps を狙える軽さに
